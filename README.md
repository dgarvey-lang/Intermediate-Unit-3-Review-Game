# Systems Strike: Unit 3 Review Game

A two-team review game for Intermediate Algebra Unit 3 (Systems of Equations), made to run on the teacher's computer and be shown on a projector.

## How to play

1. Open `index.html` in a web browser (Chrome, Edge, Firefox, or Safari). No install needed.
2. Name the two teams, pick a game length, and choose the question types.
3. Each turn, one team gets a question. Students work it out, and the teacher clicks the answer they give (or presses A–D).
4. **Correct:** that team aims and fires a missile at the other team's base. **Wrong:** the other team steals the missile.
5. To aim, use the angle and power sliders, the arrow keys, or drag on the battlefield. Press Space or click FIRE.
6. Destroy all four enemy buildings (Command HQ, Radar, Bunker, Fuel Depot) to win.

## Name spinner

Each team has a spinner wheel for picking who answers. Type student names (one per line) on the setup screen, or in the spinner itself. Open it with **Spin for who answers** on the question card or **Spin names** on a team panel. By default no name repeats until everyone on the team has been picked. Names are saved only in your browser.

Three correct answers in a row earns a bigger "Bunker Buster" missile. Watch the wind!

## Question types

Questions are generated fresh each time and match the Unit 3 Test Review:

- Reading graphs (finding the solution, writing a line's equation, how many solutions)
- Checking whether a point is a solution
- Number of solutions (one, none, infinitely many)
- Substitution
- Elimination
- Word problems (two-item price problems, break-even problems)
- Algebra review (order of operations, solving for x, solving for a variable)

Every question has a step-by-step worked solution the teacher can show after the answer.
